    Section 1.5 Optimization

    Optimization is application of derivatives in a Calculus 1 course. Fortunately, complex optimization problems are not part of the P exam. You will however, need to recall the basics of optimizing a function. Our review of optimization will be far less formal than in a calculus course.
    🔗

    Subsection 1.5.1 Optimizing a Function

    Consider the graph below:
    🔗
    The graph represents a function \(f(x)\) on a closed interval \([a,b]\text{.}\) We would like to determine the numerical values of "local extrema" - the points that are larger or smaller than all other points around them. Graphically, we see that there are local minimum at \(x=a\) and \(x=d\) and local maximums at \(x=b\) and \(x=e\text{.}\) We will also be interested in the "global extrema" - the points that are larger or smaller than all other points on the function. We see that a global maximum occurs at $x=e$ and a global minimum occurs at \(x=d\text{.}\)
    🔗
    The process of finding such extrema analytically (and by hand) requires the use of derivatives. Consider the point at \(x=b\text{.}\) If we drew a tangent line to \(f(x)\) at that point, the line would have slope \(0\text{.}\) This means that \(f'(b) = 0\text{.}\) Local minimums and maximums can occur at "bottoms of valleys" and "tops of hills,"" which are points at which \(f'(x) = 0\text{.}\) Thus, finding where a function’s derivative is equal to zero gives some candidates for local extrema.
    🔗
    Consider the point at \(x=d\text{.}\) Here, the derivative does not exist. These "sharp points" can also yield local extrema. Hence, finding where a function’s derivative does not exist gives more candidates for the local extrema. Be warned that points at which the derivative is zero or does not exist do not always yield local extrema.
    🔗
    Take the point at \(x=c\) in the graph above. The derivative does not exist at that point (slopes change suddenly), but it is not a local minimum or maximum.
    🔗
    Finally, if the function is on a closed interval, we can have local extrema at the endpoints (but not always).
    🔗
    Once we identify the points where local extrema could occur, we need to determine if we in fact do have local minimums or maximums. We could employ one of the tests (first-derivative or second-derivative) or check numerically. If one of these points is the largest or smallest values on the entire function, then we have that those points are the global extrema.
    🔗

    Optimization Steps.

    To find the local extrema of a continuous function \(f(x)\text{:}\)
    🔗
    • Find the derivative function \(f'(x)\text{.}\)
      🔗
      🔗
    • Find the values for which \(f'(x)\) is zero or does not exist.
      🔗
      🔗
    • Determine if these values represent local minimums or maximums (or neither).
      🔗
      🔗
    • If on a closed interval, check if the endpoints are local extrema.
      🔗
      🔗
    🔗
    🔗

    Example 1.5.2. Finding Local Extrema.

    Find the local extrema and global extrema on the function \(\displaystyle {f(x) = \frac{2}{3} x^3 - 2x^2 - 6x}\) on the closed interval \([-4,4]\text{.}\)
    🔗
    Solution.
    First, we find where \(f'(x)\) is zero or does not exist. \({f'(x) = 2x^2 - 4x - 6}\text{.}\) This is a quadratic function, which always exists. So, we just solve \({2x^2 - 4x - 6 = 0}\text{.}\) Using the quadratic formula gives \({x = -1}\) and \(x=3\text{.}\)
    🔗
    So, we have four points that could be minimums or maximums: \(x=-4, -1, 3, 4\) (we must include the endpoints).
    🔗
    While not formal, any easy way to check if the points at \(x=-1\) and \(x=3\) are extrema are to compare their function values with nearby \(x\) values. For example, \(f(-1.1) = 3.29\text{,}\) \(f(-0.9) = 3.29\text{,}\) and \(f(-1) = 3.33\text{.}\) So, we have a local maximum at \((-1, 3.33)\text{.}\) In a similar fashion, we can find that we have a local minimum at \((3,-18)\text{.}\)
    🔗
    At \(x=4\text{,}\) we can see that smaller \(x\) values yield smaller function values. For example \(f(4)=-13.33>-14.27 =f(3.9)\text{.}\) So, we will have a local maximum at \((4,-13.33)\text{.}\) Similarly, we can get that we have a local minimum at \((-4,-50.67)\text{.}\)
    🔗
    Lastly, we just compare the four function values at are points. We see that we have a global maximum at \((-1,3.33)\) and a global minimum at \((-4,-50.67)\text{.}\)
    🔗
    🔗
    🔗

    Example 1.5.3. Finding Global Extrema.

    Find the maximum and minimum values of the function \({\displaystyle g(x) = xe^{-2x}}\) for \({x\geq 0}\text{,}\) if any exist.
    🔗
    Solution.
    First, we find \(g'(x)\text{.}\) Using the product rule, we have \(\displaystyle g'(x)\)
    🔗
    \({\displaystyle = x\left(\frac{d}{dx}e^{-2x}\right) + e^{-2x}\left(\frac{d}{dx}x\right)} {= x\left(-2e^{-2x}\right) + e^{-2x}(1) = e^{-2x}(1-2x)}\text{.}\) First, note that this always exists. So, we just solve \(\displaystyle e^{-2x}(1-2x) = 0\text{.}\) Notice that \(e^{-2x}\ne 0\text{.}\) So, solving \(1-2x=0\) for \(x=0.5\) yields our only solution.
    🔗
    We have \(g(0.5) = 0.184\) and values around \(x=0.5\) yield smaller function values (e.g. \(g(0.4) = 0.180\)). So, we can conclude that we have a maximum at \((0.5,0.184)\text{.}\)
    🔗
    We can also get that the endpoint \(x=0\) yields a minimum at \((0,0)\text{.}\)
    🔗
    However, we need to determine the behavior of \(g(x)\) as \(x\) goes to infinity. (It may rise above our proposed maximum at \(x=0.5\) or proposed minimum at \(x=0\text{.}\)) For \(x>0\text{,}\) we see that \(g(x) >0\text{.}\) Hence, our point at \((0,0)\) is a global minimum. Further, \(\displaystyle \lim_{x\rightarrow \infty}xe^{-2x}= 0\text{,}\) which means the function tends towards \(0\text{.}\) So, our point at \((0.5,0.184)\) is a global minimum. (We could have also noted that \(g'(x)<0\) for \(x>0.5\text{,}\) which means \(g(x)\) decreases after our maximum at \(x=0.5\text{.}\))
    🔗
    🔗
    🔗
    🔗

    Checkpoint 1.5.5. Mode of a Density Function 1.

    A density function is given by \(f(x)=\frac{1}{5}e^{-x/5}\) for \(x\geq 0\text{.}\) The mode is defined as the \(x\) value that maximizes \(f(x)\text{.}\) Find the mode of \(f(x)\text{.}\)
    🔗
    Mode:
    🔗
    Answer.
    \(0\)
    🔗
    🔗
    Solution.
    Since
    🔗
    \begin{equation*} \begin{aligned} f'(x) \amp = -\frac{1}{5^2}e^{-x/5}, \end{aligned} \end{equation*}
    🔗
    the derivative is always negative for \(x\geq 0\text{.}\) Therefore, the density is decreasing on its domain, so its maximum occurs at the left endpoint. The mode is \(x=0\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 1.5.6. Mode of a Density Function 2.

    A density function is given by \(f(x)=\frac{1}{L}e^{-x/L}\) for \(x\geq 0\text{,}\) where \(L\) is a positive constant. Find the mode of \(f(x)\text{.}\)
    🔗
    Mode:
    🔗
    Answer.
    \(0\)
    🔗
    🔗
    Solution.
    Since \(L>0\text{,}\)
    🔗
    \begin{equation*} \begin{aligned} f'(x) \amp = -\frac{1}{L^2}e^{-x/L}. \end{aligned} \end{equation*}
    🔗
    This is negative for every \(x\geq 0\text{.}\) Therefore, \(f(x)\) is decreasing on its domain, so the maximum occurs at the left endpoint. The mode is \(x=0\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 1.5.7. Minimum and Maximum Values 2.

    Let \(f(x)=\frac{1}{s\sqrt{2\pi}}e^{-\frac{(x-m)^2}{2s^2}}\) on \((-\infty,\infty)\text{,}\) where \(s>0\) and \(m\) are constants. Find the minimum and maximum values of \(f(x)\text{,}\) if they exist.
    🔗
    Which statement about the minimum value is correct?
    1. A minimum value exists and is \(0\text{.}\)
      🔗
      🔗
    2. No minimum value exists.
      🔗
      🔗
    3. A minimum value exists at \(x=m\text{.}\)
      🔗
      🔗
    🔗
    Maximum value:
    🔗
    🔗
    Answer 1.
    \(\text{B}\)
    🔗
    🔗
    Answer 2.
    \(\frac{1}{s\sqrt{2\pi }}\)
    🔗
    🔗
    Solution.
    \(\frac{1}{s\sqrt{2\pi}}\) is a constant. The derivative of \(e^{-\frac{(x-m)^2}{2s^2}}\) is
    🔗
    \begin{equation*} \begin{aligned} \frac{d}{dx}e^{-\frac{(x-m)^2}{2s^2}} \amp = e^{-\frac{(x-m)^2}{2s^2}}\left(-\frac{1}{2s^2}\right)\left(2(x-m)\right)\\ \amp = -\frac{(x-m)}{s^2}e^{-\frac{(x-m)^2}{2s^2}}. \end{aligned} \end{equation*}
    🔗
    Setting this equal to zero, we find the critical point \(x=m\text{.}\)
    🔗
    Plugging in give \(\displaystyle f(m) = \frac{1}{s\sqrt{2\pi}}\text{.}\) This is the maximum value.
    🔗
    As \(x\to\infty\) or \(x\to -\infty\text{,}\) the function approaches \(0\text{,}\) but it never equals \(0\text{.}\) Therefore, no minimum value exists.
    🔗
    🔗
    🔗

    Checkpoint 1.5.8. Minimum and Maximum Values 3.

    Find the minimum and maximum values of \(f(x)=\frac{1}{10}(x-3)^2+2\) on \([0,10]\text{.}\)
    🔗
    Minimum value:
    🔗
    Maximum value:
    🔗
    Answer 1.
    \(2\)
    🔗
    🔗
    Answer 2.
    \(6.9\)
    🔗
    🔗
    Solution.
    The function is written in vertex form. Since the coefficient of the squared term is positive, the minimum occurs at the vertex:
    🔗
    \begin{equation*} \begin{aligned} x \amp = 3,\\ f(3) \amp = 2. \end{aligned} \end{equation*}
    🔗
    To find the maximum on the closed interval, compare the endpoint values:
    🔗
    \begin{equation*} \begin{aligned} f(0) \amp = 2.9,\\ f(10) \amp = 6.9. \end{aligned} \end{equation*}
    🔗
    Therefore, the maximum value is \(6.9\text{.}\)
    🔗
    🔗

    Checkpoint 1.5.9. Mode of a Density Function 3.

    A density function is given by \(f(x)=\frac{1}{k!t^k}x^{k-1}e^{-x/t}\text{,}\) where \(x>0\) and \(k,t>1\) are constants. Find the mode of \(f(x)\text{.}\)
    🔗
    Mode:
    🔗
    Answer.
    \(t\mathopen{}\left(k-1\right)\)
    🔗
    🔗
    Solution.
    The constant factor \(\frac{1}{k!t^k}\) is positive, so it does not affect where the maximum occurs. Differentiate the part depending on \(x\text{:}\)
    🔗
    \begin{equation*} \begin{aligned} \frac{d}{dx}\left(x^{k-1}e^{-x/t}\right) \amp = (k-1)x^{k-2}e^{-x/t}+x^{k-1}\left(-\frac{1}{t}e^{-x/t}\right)\\ \amp = x^{k-2}e^{-x/t}\left((k-1)-\frac{x}{t}\right). \end{aligned} \end{equation*}
    🔗
    Since \(x^{k-2}e^{-x/t}\) is positive for \(x>0\text{,}\) the critical point occurs when
    🔗
    \begin{equation*} \begin{aligned} (k-1)-\frac{x}{t} \amp = 0\\ x \amp = t(k-1). \end{aligned} \end{equation*}
    🔗
    The function increases before this point and decreases after it, so the mode is \(x=t(k-1)\text{.}\)
